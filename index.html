1. Синус, косинус, тангенс 0°–180°

В 9 классе тригонометрические функции определяются для углов от 0° до 180°. Основное тождество и формулы приведения — база для решения треугольников.

Основное тождествоsin²α + cos²α = 1
Тангенсtg α = sin α / cos α
Приведение (180° − α)sin(180°−α) = sin α
cos(180°−α) = −cos α
Приведение (90° − α)sin(90°−α) = cos α
cos(90°−α) = sin α
Запомни: для тупых углов (90° < α < 180°) синус положителен, а косинус и тангенс — отрицательны.

2. Решение треугольников

Теоремы синусов и косинусов позволяют найти неизвестные стороны и углы любого треугольника.

Теорема синусовa / sin A = b / sin B = c / sin C = 2RR — радиус описанной окружности
Теорема косинусовc² = a² + b² − 2ab·cos C
Площадь через синусS = ½ · a · b · sin C

Полезно знать

  • Сумма углов треугольника = 180°.
  • Теорема Пифагора (только для прямоугольного): a² + b² = c².
  • Средняя линия параллельна стороне и равна её половине.
  • Формула Герона (если даны три стороны): S = √(p(p−a)(p−b)(p−c)), где p — полупериметр.

3. Векторы и скалярное произведение

Одна из ключевых тем 9 класса. Скалярное произведение используется для нахождения углов и длин.

Действия с векторами

  • Сложение: правило треугольника и параллелограмма.
  • Вычитание: a − b = a + (−b).
  • Умножение на число: k·a (меняет длину, при k<0 — направление).
  • Коллинеарность: a = k·b (если векторы параллельны).

Скалярное произведение

a · b = |a| · |b| · cos α
Через координаты a · b = x₁x₂ + y₁y₂

Следствия:
• a ⊥ b, если a · b = 0.
• cos α = (a · b) / (|a|·|b|).

4. Метод координат

Расстояние между точкамиd = √((x₂−x₁)² + (y₂−y₁)²)
Середина отрезкаx = (x₁+x₂)/2, y = (y₁+y₂)/2
Уравнение окружности(x−a)² + (y−b)² = R²(a;b) — центр, R — радиус
Длина вектора|a| = √(x² + y²)

5. Правильные многоугольники

Правильный n-угольник: все стороны и углы равны. Вписанная и описанная окружности совпадают по центру.

Угол правильного n-угольникаα = (n−2)·180° / n
Сторона через R (описанная)aₙ = 2R · sin(180°/n)
Радиус вписанной окружностиr = R · cos(180°/n)
Площадь через периметр и rS = ½ · P · r
Для правильного треугольника (n=3): R = a/√3, r = a/(2√3). Для квадрата (n=4): R = a/√2, r = a/2.

6. Длина окружности и площадь круга

Длина окружностиC = 2πR
Длина дуги (α — градусы)l = (πR / 180) · α
Площадь кругаS = πR²
Площадь сектораS = (πR² / 360) · α

Вписанные и описанные четырёхугольники

  • Вписанный четырёхугольник: сумма противоположных углов = 180°.
  • Описанный четырёхугольник: суммы противоположных сторон равны (a + c = b + d).

7. Площади фигур — быстрое повторение

Эти формулы пригодятся и в задачах на векторы/координаты, и в простых заданиях первой части.

ТреугольникS = ½ · a · h
S = ½ · a · b · sin C
ПараллелограммS = a · h
S = a · b · sin α
ТрапецияS = ((a+b)/2) · h
РомбS = ½ · d₁ · d₂
КвадратS = a²
ПрямоугольникS = a · b
Отношение площадей подобных фигур равно квадрату коэффициента подобия: S₁/S₂ = k².

⚡ Что ещё часто спрашивают

Сумма углов

  • Треугольник: 180°.
  • Выпуклый n-угольник: (n−2)·180°.

Свойства равнобедренного треугольника

  • Углы при основании равны.
  • Медиана к основанию = биссектриса = высота.

Прямоугольный треугольник

  • Катет против угла 30° = ½ гипотенузы.
  • Медиана к гипотенузе = радиус описанной окружности.

Движения плоскости

  • Осевая симметрия, центральная симметрия, поворот, параллельный перенос.
  • Движение сохраняет расстояния и углы.
